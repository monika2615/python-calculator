
# Python Calculator

A basic calculator built using Python that performs arithmetic operations like:
- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Floor Division
- Exponentiation

## Technologies Used
- Python

## How to Run
1. Download or clone this repository
2. Run the file:
3. ![Calculator Output](calculator-output.jpg)

python calculator.py

The main Python code is available in:
- calculator.py
